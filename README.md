# SmartCal
SmartCal is a simple and user-friendly calendar application developed using Python and Tkinter. It allows users to enter a year and view the complete yearly calendar through an interactive GUI. This project helped me improve my Python, GUI development, and problem-solving skills while gaining practical experience in creating applications.
## ✨ Features
- 📆 View the calendar for a selected year.
- 🔍 Find the day of a specific date.
- 🕒 Display the current time.
- 🖥️ Simple and interactive graphical user interface.
- 🎨 User-friendly design.

## 🛠️ Technologies Used
- *Language:* Python
- *GUI:* Tkinter
- *Calendar:* Python Calendar Module
- *Date and Time:* Python Datetime Module
- *Version Control:* Git and GitHub

## 💻 Requirements
- Python 3.x
- Visual Studio Code or another Python editor
- Tkinter
